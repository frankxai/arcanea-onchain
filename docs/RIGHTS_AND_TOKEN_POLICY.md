# Rights And Token Policy

Status: local/testnet policy
Last updated: 2026-06-27

This workspace records access, provenance, software licenses, and programmable
IP pointers. It does not replace off-chain contracts, split sheets, distributor
records, publishing administration, or counsel review.

## Allowed First

- Software license tokens for skill packs and operator packs.
- Access passes for gated communities or private drops.
- Provenance certificates for finalized assets.
- Collectibles with no revenue promise.
- Story Protocol registration for assets whose off-chain rights are clean.

## Blocked Until Counsel Review

- Any token that implies revenue, royalty, profit, yield, catalog ownership,
  fractional ownership, investment return, or governance over a revenue pool.
- Any mainnet contract that attaches commercial IP rights.
- Any split or payout design involving collaborators, artists, partners, or
  public buyers.
- Any transferable license that could be confused with a security or financial
  product.

## Off-Chain Terms Win

Contract metadata can point to a terms hash. The terms document controls what
the buyer or holder receives. If the terms document is missing, the token grants
only the minimum technical function expressed in the contract.

## Required Per Deployment

- Contract name and version.
- Network and chain ID.
- Admin wallet and role holders.
- Treasury wallet and withdrawal policy.
- Metadata base URI.
- Terms hash.
- Manifest hash.
- Counsel status.
- Security review status.
- Emergency pause owner.
